## The stack

Three tools, three layers, one idea: infrastructure decisions should be written
down before they are executed, not discovered afterwards in a dashboard.

<CardGrid>
	<Card title="Kuberina" icon="seti:kubernetes">
		**Offline scheduling for heterogeneous Kubernetes.** Reformulates pod
		placement as multi-dimensional bin packing, borrowed from how mega-vessel
		shipping lines stow containers. Produces a reviewable blueprint instead of
		an opaque runtime decision.

		[Overview](/kuberina/) · [Tutorial](/kuberina/tutorials/first-blueprint/) · [Paper](/research/kuberina-stowage-scheduling/)
	</Card>
	<Card title="Helvilette" icon="seti:config">
		**Pull-based GitOps delivery for Ansible.** Agents pull playbooks from Git
		and reconcile at the systemd layer. One last SSH session to install it,
		then port 22 closes forever.

		[Overview](/helvilette/) · [Tutorial](/helvilette/tutorials/quickstart/)
	</Card>
	<Card title="Kallisto" icon="seti:lock">
		**Secret delivery for the request path.** A node-local cache in front of
		your existing Vault or OpenBao, speaking the KV-v2 API. Adopting it is one
		environment variable. So is removing it.

		[Overview](/kallisto/) · [Tutorial](/kallisto/tutorials/quickstart/)
	</Card>
</CardGrid>

## Where each one sits

Naughtian is deliberately layered. Kuberina decides *where workloads go* before
anything runs. Helvilette keeps *the machines underneath* converged on their
desired state. Kallisto serves *the secrets those workloads need* without a
round trip to the root of trust.
